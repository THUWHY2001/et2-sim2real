# ET2 左臂黑盒模型集成设计

## 目的

以 `arm_model.zip` 中的 2026-07-28 CMD 数据为左臂唯一建模源，覆盖现有手臂 J3/J5/J6 简化页，建立 J0–J6 统一的闭链运动学、质量属性、重力矩、惯性力矩和连接副阻力分析页面。

## 数据与边界

- 首次加载必须先执行黑盒 `validate()`；不得全文读取、复制解释或手工重建 `model.json`。
- 仅使用 18 个 `arm_l_*` 刚体，总质量 `3.7249532 kg`；`Hand_L` 与 `waist_link3_3_shoulder_L` 只作为接口，不计质量。
- 全局重力仅使用一次 `[0,0,-9.80665] m/s²`。
- 数据版本固定为 2026-07-28 CMD。9月 PDF 的移动副反向和关节类型修改只显示为版本提示，不进入求解。
- 黑盒不提供完整约束反力或电机力矩求解器；本次动力学采用刚体质心/惯量随动、虚功重力矩和广义有效惯量，不宣称得到完整约束载荷。

## 关节与驱动

| 页面 | 输出 | 真实主动输入 |
|---|---|---|
| J0 | Shoulder Pitch | J0 旋转轴 |
| J1 | Shoulder Roll | J1 旋转轴 |
| J2 | Shoulder Yaw | J2 旋转轴 |
| J3 | Elbow Pitch | 肘部单推杆，输出轴被动 |
| J4 | Elbow Yaw | J4 旋转轴 |
| J5 | Wrist Roll | 腕部两推杆，输出轴被动 |
| J6 | Wrist Pitch | 腕部两推杆，输出轴被动 |

J0/J1/J2/J4 直接采用真实主动旋转轴；J3 调用 `elbowPitchToRod()` 后用 `elbowRodToPitch()` 回代；J5/J6 调用 `wristPoseToRods()` 后用 `wristRodsToPose()` 回代。不得同时给 J3/J5/J6 输出轴施加独立 Motion。

## 运动学和刚体随动

- 主链 J0→J6 使用 CMD 关节初始轴线与右手转角逐级刚体变换。
- 肘部支链和腕部双推杆继续调用黑盒已有正逆解；仅补充只读几何快照接口，将黑盒内部已求得的闭链点提供给显示和质量随动，不复制第二套求解器。
- 每个刚体使用自身 `com_body_local_initial_mm`、初始世界 COM、惯量及所属刚体变换；不得把18个质量集中到关节中心。
- `J1=+20°、J3=-20°` 参考姿态只做回归测试，关节中心需与 `pose_reference.json` 一致；默认页面仍为 1 Hz、±10° 单轴激励。

## 阻力与动力学

- 连接副阻力仍按瞬时广义速率绝对值折算到目标输出轴；旋转/球副输入 N·m，移动副输入 N。
- 页面分别显示静摩擦启动力矩、运行阻力、完整周期贡献度、重力矩、惯性力矩和总需求力矩。
- 重力矩由18个随动 COM 的势能对目标关节角数值求导；有效惯量由各刚体 COM 线速度与角速度、COM 惯量计算。
- 未经实测标定的负载—摩擦修正默认不参与计算，并明确为预留接口。

## 页面

- 使用一个统一 J0–J6 页面模板和统一运行时，导航显示 J0、J1、J2、J3、J4、J5、J6。
- 每页包含：三维硬点/连杆示意、输出角与真实主动输入读数、闭链残差、双向静/动摩擦输入、实时及周期贡献度、总力矩组成、18刚体质量表、版本范围说明。
- 原 J3/J5/J6 简化模型和页面由新页面直接覆盖，不作为计算回退源。

## 方案取舍

- 采用统一运行时和统一模板：计算口径一致，后续摩擦实测、载荷标定只需修改一个入口。
- 未采用“保留旧 J3/J5/J6 再补四页”：该方案会保留多套硬点、传动和质量实现，难以证明版本一致。
