# ET2 头颈黑盒模型集成设计

## 目标

用黑盒包中的原始 CMD 硬点、13 个刚体质量属性和非线性闭链求解器替换现有头颈简化模型。页面沿用躯干模块的信息结构，覆盖现有 J0/J1 页面并新增 J2 Yaw；保留独立硬点公差页面入口。

## 已验证输入

- `validate()`：通过；头颈质量 `2.8109963 kg`；往返残差 `3.55e-13 mm`。
- 左右推杆 `+1/+1 mm`：Roll `0°`，Pitch `+2.569408°`。
- 左右推杆 `+1/-1 mm`：Roll `+1.849923°`，Pitch `+0.009610°`。
- 重力仅采用 `[0,0,-9.80665] m/s²`，不包含胸腰安装边界质量。

## 方案

1. **黑盒适配层（采用）**：原样复制 `model.json` 和 `neck_blackbox.mjs`，新增浏览器适配层和动力学扩展。闭链位置求解始终调用 `rodsToPose()` / `poseToRods()`。
2. 重写求解器：会重复已有代码并引入几何偏差，不采用。
3. 独立 iframe：难以复用当前导航、贡献度和页面状态，不采用。

## 运动与页面

- J0 Roll：页面给定输出 `±10°`，用 `poseToRods()`反解两推杆行程；运行时用行程再调用 `rodsToPose()`校核输出。
- J1 Pitch：同上；左右推杆主要同步同向伸缩。
- J2 Yaw：Yaw 为唯一主动旋转输入，推杆行程与 Roll/Pitch 相对姿态保持不变。
- 组合页：Yaw、左推杆、右推杆为三个主动输入，Roll/Pitch 由 `rodsToPose()`求解。
- 每帧显示两侧行程、Roll/Pitch/Yaw、闭链残差和求解迭代次数。
- 页面顺序与躯干一致：三维机构、运动输入、连接副阻力输入、原始实时/周期贡献度、承载参数、加载后实时/周期贡献度、总力矩组成、质量属性范围。

## 动力学与贡献度

- 每个 PART 的初始世界质心和 COM 惯量绑定到其刚体；随刚体姿态及推杆伸缩更新。
- 连接副阻力通过瞬时传动率折算到目标输出轴；启动和运行阻力分开。
- 负载修正以各副名义承载、预紧力和可调负载系数计算；加载前结果保留并与加载后并列。
- 总需求力矩分别显示连接副阻力、重力矩、1 Hz 惯性力矩及其有符号和，不把重力或惯性分摊给某个连接副。
- 黑盒只提供刚性位置。名义承载是工程估算接口，不宣称为完整约束反力；定量载荷结果需实测预紧力/摩擦参数校准。

## 验证与边界

- 自动化验证 `validate()`、两组参考工况、Yaw 不改变相对姿态、每帧闭链残差、13 刚体质量和总质量。
- 对 J0/J1/J2 运行 1 Hz、±10° 周期，检查连续收敛、质心随刚体运动、总力矩各分项有限。
- 不修改腿足、躯干、手臂页面；不读取或复制胸腰质量；不简化或重建头颈传动关系。
