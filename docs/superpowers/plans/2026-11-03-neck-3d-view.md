# 头颈 J0/J1 可旋转三维视图 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将头颈 J0、J1 的二维机构投影替换为可拖拽旋转、滚轮缩放和恢复视角的真实硬点三维视图。

**Architecture:** 新增独立的原生 SVG 三维投影工具，负责相机旋转、缩放和三维到二维投影；现有 `neck-joint.fragment.html` 只负责机构点线组装与交互绑定。动力学、重力矩和贡献度仍由 `NeckModel` 计算，显示层不反向修改模型状态。

**Tech Stack:** 原生 JavaScript、SVG、Pointer Events、Node.js 内置测试框架

**Spec:** `docs/superpowers/specs/2026-11-03-neck-3d-view-design.md`

## Global Constraints

- 不引入 Three.js、WebGL 或外部 CDN。
- J0、J1 共用同一套投影和交互代码。
- 不修改硬点、运动学、摩擦、重力矩、承载力或贡献度算法。
- 同时支持鼠标和触控拖拽。

## Review Focus

- 极端俯仰角下投影值必须保持有限，不能出现 NaN。
- 缩放必须限制在合理范围，避免机构消失或溢出。
- 拖拽旋转只改变相机，不改变当前关节角度和计算结果。
- 页面动画更新时必须保留用户选择的相机角度。
- 小屏幕和触控设备上不得触发浏览器页面拖动冲突。
