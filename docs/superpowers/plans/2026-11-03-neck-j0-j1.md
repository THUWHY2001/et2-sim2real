# Neck J0/J1 Sensitivity Pages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build separate neck J0 Roll and J1 Pitch mechanism/sensitivity pages with measured friction inputs, preload traceability and gravity torque.

**Architecture:** A shared pure JavaScript 3D kinematics model rotates platform points and COM around the selected equivalent axis, differentiates rod/fish-eye motion numerically and maps measured local friction by virtual work. One parameterized HTML fragment renders the two planar views and shared analysis controls.

**Tech Stack:** Vanilla JavaScript, SVG, HTML/CSS, Node test runner

**Spec:** `docs/superpowers/specs/2026-11-03-neck-j0-j1-design.md`

## Global Constraints

- J0 and J1 are separate pages and only one joint is excited at a time.
- Gravity is `-Z`; mass is 2.447 kg and COM is `(-9.851,0.204,408.752)` mm.
- Preload is recorded but does not alter friction without calibration data.
- Friction contribution excludes gravity; total required torque includes both.

## Review Focus

- J0 rods change in opposite directions while J1 rods change synchronously.
- Gravity torque sign follows each axis right-hand convention.
- Inactive cross-axis bearings have zero relative-rotation contribution.
- Zero or asymmetric friction inputs remain finite and normalize safely.
- Animation reversal selects the correct positive/negative measured friction.
