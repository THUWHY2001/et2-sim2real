# 手臂 J5 并联双推杆 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有灵敏度分析网站中新增基于三维硬点的手臂 J5 并联双推杆模型和贡献度分析页面。

**Architecture:** 独立 `arm-j5-model.js` 使用 Rodrigues 公式驱动下端刚体绕等效轴旋转，并通过中心差分输出两根推杆和四个鱼眼副的雅可比。`arm-j5.fragment.html` 复用现有方向摩擦、公差和图表控件，构建静态、1 Hz 动态及长度敏感度界面；构建脚本负责生成并发布独立页面。

**Tech Stack:** 原生 HTML/CSS/JavaScript、SVG、Node.js 回归测试、GitHub Pages。

**Spec:** `docs/superpowers/specs/2026-10-30-arm-j5-design.md`

## Global Constraints

- 三维硬点坐标和 J5 轴线必须逐值采用设计文档数据。
- 连杆1固定；连杆2和两个下端点作为同一刚体绕 J5 轴旋转。
- 1 Hz、±10°；正反向摩擦独立输入。
- 推杆不作为定长杆；二维 SVG 仅显示，计算始终使用三维坐标。
- 不引入第三方运行时依赖。

## Review Focus

- 轴线方向反转：只改变正负角定义，不应改变绝对峰值和标准态几何；由模型测试覆盖。
- 两根推杆同步性：标准硬点下任一角度长度及雅可比应一致；由模型测试覆盖。
- 零速换向：动态摩擦方向不得产生 NaN；由模型测试覆盖。
- 非法杆长：调节后几何不可能时页面必须显示错误并停止动画；由页面测试覆盖。
- 缓存旧资源：页面脚本和样式必须更新版本号；由构建壳测试覆盖。
