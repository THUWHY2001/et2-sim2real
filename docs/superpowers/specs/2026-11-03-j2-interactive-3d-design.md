# J2 可旋转三维机构图设计

## 目标

将腿足 J2 阻力贡献页现有 X–Z 二维机构图升级为基于硬点 X/Y/Z 坐标的可旋转三维机构图，使用户能看清各转轴、连杆和推杆的空间关系。

## 范围

- 仅修改 `j2.html` 对应的阻力贡献页面，不修改 J2 间隙/死区页。
- 鼠标拖动或触控单指旋转，滚轮缩放。
- 提供“X–Z 侧视”和“重置视角”。
- 三维机构随现有 J2 角度滑块及 1 Hz、±10°动画同步运动。
- 标注 J2 等效旋转轴、轴1、轴2、轴3、推杆上下滑动轴承和主要连杆。
- 保留现有节点坐标表和所有阻力、贡献度、公差计算。

## 实现方案

采用原生 Canvas 3D 投影：以现有运动学解算结果作为 X/Z，使用各硬点原始 Y 坐标生成轴线和杆件；经视图旋转、透视投影后绘制。该方案不引入第三方依赖，适合 GitHub Pages 静态部署。

备选方案包括继续使用 SVG 伪三维，以及引入 Three.js。前者空间表达不足，后者增加依赖和维护成本，因此不采用。

## 约束

- 三维图只改变呈现方式，不参与也不改变现有计算。
- 无 WebGL 依赖；Canvas 不可用时保留可读提示。
- 标签需避免明显重叠，视图操作不得触发页面滚动冲突。
- 桌面端和移动端均可操作。
