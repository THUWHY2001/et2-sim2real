# J2 死区领导决策视图设计

## 目标

把页面重点从动态机构演示转为静态单因素灵敏度分析，直接回答“哪个连接副的间隙对J2等效旋转轴死区影响最大，以及应优先管控谁”。

## 选定方法

1. 每次仅启用一个连接副的间隙，其他连接副全部清零。
2. 将该副正、负侧输入按相同比例从0扫描到当前输入值；当前输入值作为本轮分析的管控上限。
3. 每个扫描点在J2姿态 −10° 至 +10°范围内离散求解，取最大J2输出死区。
4. 灵敏度为最大死区除以该副正、负侧总间隙；J2使用 °/°，其他副使用 °/mm。
5. 实际影响量为100%管控上限下的最大J2死区；贡献度为各副实际影响量归一化占比。
6. 灵敏度用于设计风险判断，贡献度用于当前实物管控排序；不把不同单位的原始灵敏度强行合并成一个数值排名。

## 页面

- 顶部静态结论卡：最高实际贡献、最高毫米间隙灵敏度、建议优先管控项。
- 两张排名：单位间隙灵敏度、实际贡献度。
- 每个连接副一张“间隙利用率—J2最大死区”曲线，标注输入上限、最大死区和最敏感姿态。
- 汇总表：连接副、输入上限、灵敏度、最大死区、最敏感姿态、贡献度。
- 动态机构演示放入默认折叠的“辅助理解”区域。

## 边界

- 这是刚体、准静态、单因素筛选；不把各副耦合强行解释为严格可加。
- 当前输入若为0，该副影响量和贡献度为0。
- J2径向毫米间隙仍不在缺少支撑几何时强制换算。
