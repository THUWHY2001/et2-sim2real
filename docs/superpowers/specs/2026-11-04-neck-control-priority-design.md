# 头颈硬点管控优先级设计

## 目的

将动态贡献结果转化为可直接判断“哪个硬点应优先管控、哪个可评估放宽”的简明排名。

## 默认展示

- 按硬点列出排名、静摩擦周期贡献度、动摩擦周期贡献度、周期峰值影响和建议。
- 周期贡献度采用整周期有符号 Shapley 力矩的绝对值积分后归一化：`C_i=∫|φ_i(t)|dt / Σ∫|φ_j(t)|dt`。
- 综合优先级取静态贡献度、动态贡献度中的较大值；同时检查峰值，避免总体占比低但局部姿态突增。
- 建议分级：高（≥30%）优先管控；中（10%–30%）保持；低（<10% 且峰值不异常）可评估放宽。阈值在页面明确标注为工程筛选值，不直接替代公差批准。
- 复杂周期曲线放入“详细计算”折叠项，默认收起。

## 不变项

计算模型、1 Hz ±10°激励、逐时刻精确 Shapley、J0/J1参数接口均保持不变。

## 验收

排名百分比各模式分别合计100%；单点为100%；排名与周期积分一致；J0/J1页面可用且原结果不回归。
