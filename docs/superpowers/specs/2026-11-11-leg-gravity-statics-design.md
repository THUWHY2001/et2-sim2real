# ET2 左腿重力准静态约束反力求解器设计

## 目的

在现有 ET2 左腿完整三推杆闭链运动学之上，建立可审计的六维多刚体重力静力平衡求解器。第一版先回答“在明确边界条件下，哪些铰点反力和推杆保持力能够由现有理想刚体模型唯一确定”，不提前计算摩擦圆，也不把数学上非唯一的反力包装成真实载荷。

## 现状核查

- `leg_full.mjs` 已提供 20 个运动刚体、25 个运动副、50 个 Marker、23 个硬点、实时世界变换及质心世界坐标。
- `leg-full-runtime.mjs` 已提供 J2/J3/J4 输出反解、1 Hz ±10° 工况、速度传动率、重力势能和等效惯量。
- 当前不存在约束反力或拉格朗日乘子求解器。
- `nominalLoads()` 仅按重量分组和推杆方向估算承载，不是运动副约束反力，不得复用于新求解器的反力结果。

## 选定方法与排除方法

### 选定：刚体自由体图 + 约束扳手基 + 尺度归一化 SVD 分析

对 20 个运动刚体分别建立三维力平衡和三维力矩平衡。每个运动副按照其理想自由度生成允许传递的约束扳手基，将全部未知约束反力、约束力矩及推杆轴向保持力组成线性方程 `A x = b`。通过带行列尺度归一化的 SVD 或数学等价的秩揭示分解判断整体及每个输出量是否唯一。

该方法直接复用现有刚体、Marker、运动副轴向和当前姿态，能够明确暴露闭链超静定，不依赖 Adams，也不会用最小范数掩盖非唯一性。

### 排除：串联机构递推受力

递推切割适用于树状机构，无法正确处理当前三套闭环和复合铰点，会人为指定闭环载荷分配。

### 排除：把输出重力矩或推杆力分摊给铰点

总重力保持力矩不能唯一反推出闭链内部各铰点反力。该方法与任务目标冲突。

## 第一版理论边界

- 唯一世界接口是现有 `J_LEG_L_HIP_roll_RE`，即 `base_link ↔ leg_l_link1`。`base_link` 固定于世界且不计入腿部质量；不固定其他刚体。
- 足端无地面接触、无外部载荷，属于“机身固定、左腿悬空”的理论基准工况。
- J0、J1、J5 使用当前闭链工况给出的角度，并作为位置保持旋转副；不强制改成零位。其轴向保持力矩作为未知约束反力输出。
- J2、J3、J4 是被动输出旋转副，不传递绕自身自由轴的理想约束力矩。
- 三根移动副均包含五维理想移动副约束扳手和一个独立的轴向执行器保持力未知量。
- 脚趾角度沿用当前模型工况。由于 CMD 中脚趾 Motion 为位置保持而物理执行器未核实，第一版将脚趾旋转自由度标记为“理想位置保持边界”，输出保持力矩并明确其可信度为边界假设。
- 首个验收姿态为 J2=-27.5°、J3=51.57°、J4=-24.06°；随后才扩展到三个单关节各自的 1 Hz、±10° 全时序。

## 约束扳手模型

所有位置使用米，力使用牛顿，力矩使用牛顿米。运动副中心和轴向直接取当前姿态下对应 Marker，不改变硬点。

### I/J Marker 与统一参考点

每个运动副先读取当前姿态下 I/J 两侧 Marker。未知内部扳手统一定义在同一世界参考点 `p_ref`，默认取两侧 Marker 的中点，并记录 I/J 位置残差。作用于 J 刚体的标准扳手为 `(F, M_ref)`，作用于 I 刚体的标准扳手为 `(-F, -M_ref)`。

需要在各自 Marker 表示力矩时，按空间扳手平移关系转换：

- `M_j = M_ref + (p_ref - p_j) × F`
- `M_i = -M_ref + (p_ref - p_i) × (-F)`

因此即使移动副两侧 Marker 存在微小不重合，内部作用反作用统一到世界参考点后仍严格成对平衡，不能把两个局部 Marker 上的力矩直接取反。

- 球副：三个正交力分量，不传递力矩。
- 自由旋转副：三个正交力分量、两个垂直于轴线的力矩分量；不传递沿轴力矩。
- 位置保持旋转副：在自由旋转副基础上增加沿轴保持力矩。
- 移动副：两个垂直于移动轴的力分量、三个力矩分量；推杆轴向保持力作为单独未知量。
- 固定副：三个力分量和三个力矩分量。固定副参与刚体平衡，但后续不作为摩擦副。

每个内部运动副对相连两刚体施加大小相等、方向相反的扳手。力矩平衡统一对世界原点计算，包含 `r_joint × F`、运动副直接力矩以及 `r_com × m g`。

## 线性求解与唯一性

求解前分别对平衡方程行和未知量列进行尺度归一化，避免 N 与 N·m、不同力臂及不同扳手基造成虚假秩亏。对缩放矩阵执行 SVD 秩揭示，奇异值阈值同时采用相对阈值和机器精度尺度。零空间基映射回物理未知量坐标后，再判定每个反力分量是否唯一。

求解器输出：

- 方程数、未知数、`rank(A)`、`rank([A|b])`、零空间维数、奇异值谱及缩放后条件数；
- 方程是否一致；
- 最大力残差、最大力矩残差和整体重力平衡残差；
- 每个运动副的 Fx/Fy/Fz、合反力、相对轴线的轴向载荷和径向载荷；
- 三根推杆轴向保持力；
- J0/J1/J5/脚趾的位置保持力矩；
- 每项结果的唯一性及来源说明。

SVD 允许构造一个数值特解，但该特解只用于残差验证和提取数学上与零空间正交的唯一线性量。非唯一分量、非唯一合力、非唯一径向载荷和非唯一推杆力不得显示特解数值，统一返回 `null` 并标记 `indeterminate`。绝不将最小二乘或最小范数特解称为真实载荷。

若增广矩阵秩大于系数矩阵秩，则边界与姿态不一致，整个求解失败；不得继续生成反力。

## 模块接口

新增独立模块 `leg-gravity-statics.mjs`，不修改黑盒运动学：

- `createLegGravityStatics(model)`：读取质量、运动副和轴向定义。
- `assemble(solution, boundary)`：从当前闭链姿态生成 `A`、`b` 和未知量元数据。
- `solve(solution, boundary)`：执行秩、零空间、残差及唯一性分析。
- `solveNominal()`：求解基准姿态。
- `solveCycle(outputJoint, options)`：在基准姿态验证通过后，沿用现有单关节 1 Hz ±10° 时序逐点求解。

`boundary` 必须显式记录世界固定接口、足端接触状态、J0/J1/J5 保持状态和脚趾状态。缺项时拒绝求解，不自动补支撑条件。

## 约束反力与摩擦接触载荷的边界

本阶段输出的是理想运动副为维持刚体平衡所传递的合约束扳手，不把其合反力或径向分量直接命名为摩擦接触法向载荷 `N`。

后续摩擦阶段必须按实体接触形式单独建立映射：销轴需要轴径、接触包角及轴瓦载荷分布；球铰需要球面接触法向合力；滚动轴承需要径向/轴向载荷与轴承内部载荷关系；移动副需要导向面接触和偏载分配。缺少相应几何或接触条件时，即使约束合反力唯一，也只能标记为“可作为接触载荷估算输入”，不能直接进入 `mu * N * r`。

## 重力虚功交叉校验

单姿态静力平衡通过后，使用现有有符号移动副速度雅可比 `dL_i/dq`，将三根推杆保持力折算为目标输出轴广义力：

`tau_rods = sum(F_rod_i * dL_i/dq)`。

J0/J1/J5 和脚趾在目标 J2/J3/J4 虚位移路径中保持不动，其保持力矩对应的虚位移为零。`tau_rods` 按统一符号约定与现有势能微分得到的重力保持力矩 `dV/dq` 交叉验证。两者的绝对残差和相对残差都必须输出；校验不通过时不得宣称推杆保持力可信。

## 验证

1. 第一验收门只使用 J2=-27.5°、J3=51.57°、J4=-24.06° 的静止姿态；未全部通过前不开发 1 Hz 时序。
2. 基准姿态闭链运动学结果必须与现有模型完全一致。
3. 每个内部运动副在统一世界参考点上的作用扳手必须成对相反；I/J Marker 不重合时的力矩平移关系必须单独测试。
4. 每个刚体的六维平衡残差必须低于明确的数值阈值。
5. 世界固定接口反力与全部腿部重力满足整体力平衡；整体力矩平衡同时通过。
6. 报告尺度归一化前后的矩阵尺寸、秩、零空间维数、条件数、奇异值和残差，并用物理坐标零空间投影逐项判定唯一性。
7. 三根推杆保持力通过有符号传动雅可比折算后，必须与势能微分重力保持力矩通过虚功校验。
8. 人为移除必要保持边界时，求解器必须报告不一致或新增自由度，而不是生成伪载荷。
9. 单姿态验收报告必须逐一列出 25 个运动副中可唯一确定与不能唯一确定的 Fx/Fy/Fz、轴向/径向载荷和力矩分量，并说明是否足以进入摩擦接触载荷估算。
10. 单姿态全部通过后，才允许把相同求解器扩展到 J2/J3/J4 三种单关节时序；其他两个输出保持基准姿态，三根推杆均进入受力矩阵。
11. 第一版所有结果统一标注“重力准静态理论载荷”：不含惯性、装配预紧、接触、摩擦反馈和结构柔度，不能等同于 1 Hz 真实动态载荷。

## 非目标

- 本阶段不计算摩擦圆、动摩擦力矩或静摩擦阈值。
- 不加入足地接触、外载、预紧、惯性、关节刚度或摩擦—反力迭代。
- 不修改硬点、闭链求解、关节角定义或现有阻力页面。
- 不进行页面美化；仅提供足够检查方程、反力唯一性和残差的工程输出。

## 后续衔接

只有当某运动副的径向/法向载荷能够唯一确定，或被人工/传感器载荷覆盖时，下一阶段摩擦圆模块才允许使用该载荷。载荷来源必须随结果保存为动力学求解值、人工输入、传感器值或待补参数。
