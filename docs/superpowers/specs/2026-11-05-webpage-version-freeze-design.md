# 网页1冻结与网页2副本设计

## 目的

保存当前 GitHub Pages 的模型、参数、计算逻辑和页面状态，作为不可直接修改的“网页1”；后续功能变更在独立副本“网页2”中进行。

## 采用方案

- 当前根目录继续发布为网页1：`/et2-sim2real/`。
- 在同一仓库建立完整、自包含的 `web2/` 副本，发布为网页2：`/et2-sim2real/web2/`。
- 为当前提交建立 Git 标签 `webpage-1`，用于准确恢复网页1代码与数据。
- 网页2复制页面、样式、脚本和模型数据，不引用网页1中的可变资源。
- 后续默认只修改 `web2/`；除非用户明确要求，不修改网页1根目录。

## 验收

- 网页1原网址与内容保持不变。
- 网页2可从独立网址打开，主要页面与网页1一致。
- 网页2内部导航始终停留在 `web2/`。
- 仓库有明确的冻结说明和恢复标签。

## 不包含

- 不新建 GitHub 仓库或域名。
- 本次不改变计算模型、默认参数或页面功能。
