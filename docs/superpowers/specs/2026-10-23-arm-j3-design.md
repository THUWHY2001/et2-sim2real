# 手臂 J3 灵敏度页面设计

## 目标

在现有“模块连接副-等效旋转轴的灵敏度分析”网站的手臂模块中增加独立的 `arm-j3.html` 页面，以与腿足 J2/J3/J4 相同的排版和交互展示手臂 J3 机构、双向摩擦输入、1 Hz ±10° 激励及贡献度。

## 几何与约束

- J3 等效轴由 `(-37.709,301.469,107.885)` 与 `(-37.047,231.932,82.584)` 定义，并固定在空间中。
- 主动杆 L 从 J3 轴到 P 点 `(-53.292,267.460,92.730)`，绕 J3 轴转动。
- Z 型连杆连接 P 与 Q `(-77.299,260.564,111.055)`。
- 定长杆 K 连接 Q 与固定点 R `(-30.952,261.768,108.958)`；R 在空间中固定。
- 推杆 B 端鱼眼中心 S `(-63.991,213.390,240.935)` 固定，只允许推杆绕平行于 J3 的轴轻微摆转。
- 推杆移动副的初始正方向由 Q 指向 T `(-74.251,252.723,32.678)`；运动时该方向随推杆摆角转动。

## 计算方法

- 在垂直于 J3 轴的局部二维平面中，通过两圆交点闭环解算 Q；选取靠近名义 Q 的分支。
- 将二维结果映射回三维坐标用于推杆计算。
- 以固定 S 到 Q 的姿态变化确定推杆摆角；将名义 Q→T 方向和 S→T 刚体偏置同步绕 B 端轴旋转。
- 通过中心差分计算 P、Q、R、B 各旋转副的相对角速度雅可比和移动副相对速度雅可比。
- 静摩擦按 `阻力 × |雅可比|` 折算；运行阻力包含库仑项与黏性项，并根据局部速度符号自动选择正/反向参数。
- 激励为 `q(t)=10°·sin(2πt)`，分别累计正、反行程耗散与各连接副贡献度。

## 页面范围

- 首页“手臂”模块增加 J3 入口并标记已建立。
- 手臂 J3 页面沿用现有工程化页头、机构图、输入表、统计卡片、贡献度曲线、缩放/全屏控制。
- 连接副包括 P 副、Q 副、R 副、B 端鱼眼副和推杆移动副。
- 不修改现有腿足 J2/J3/J4 的计算结果。

## 采用方案与取舍

- 采用“二维闭环＋三维推杆”：平行轴四杆闭环在局部平面中稳定求解，推杆保留三维方向和摆转影响。
- 不采用全三维非线性约束求解，因为现有闭环均为平行轴机构，增加复杂度但不提高已知约束下的可信度。
- 不采用纯二维推杆，因为 Q→T 存在明显轴外分量，会改变移动副雅可比。
