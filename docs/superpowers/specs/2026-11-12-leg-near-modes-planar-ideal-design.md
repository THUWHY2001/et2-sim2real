# ET2 腿部近零模态与理想平面模型设计

## 目标

在不修改 `legacy-ball`、`pin-revolute-v1`、原始 CMD 硬点和既有报告的前提下：

1. 定位三维被动约束矩阵的三个近零模态及其具体约束来源。
2. 新建独立 `pin-planar-ideal-v1`，用于 J5=0、X–Z 平面内 J2/J3/J4 的重力准静态理论分析。

## A：三维近零模态

- 对严格被动约束雅可比做尺度归一化 SVD，保留真实奇异值与谱间隙。
- 输出三个近零右奇异速度模态的每刚体线速度、角速度，以及投影到 J2/J3/J4 的输出速度。
- 用现有闭链运动学对 J2/J3/J4 做中心有限差分，形成实际 120 维刚体速度向量。
- 将速度代入严格被动约束雅可比，按运动副和约束分量输出功率/速度残差，定位主导约束。
- 单独核查三根移动副轴向、局部 Marker 偏置、横向残差及雅可比列的参考点变换。
- 近零模态只用于诊断，不通过修改 SVD 阈值改变严格静力结论。

## B：理想平面模型

- 模型 ID：`pin-planar-ideal-v1`；父数据仍为原 CMD 几何，独立于两套三维模型。
- 固定 J5=0；所有运动限制在 X–Z 平面；六根端部销轴严格沿世界 Y。
- 硬点取原始 X、Z；统一把 Y 投影到基准平面 `Y=93.00025 mm`。
- 三根移动副方向由各推杆上下端硬点的精确 X–Z 连线构造，不沿用 CMD 中小量三维偏轴。
- 逐项记录硬点 Y 投影、移动副轴向修正角和 Marker 横向偏差。
- 平面约束使用每刚体 `(vx,vz,omega_y)` 三自由度；输出 J2/J3/J4 三个独立运动自由度及推杆长度雅可比。
- 重力使用原 20 个刚体质量和各自随动质心；先由势能微分得到三个输出保持力矩，再由 `J_length^T F + tau_g = 0` 求三根推杆保持力。
- 平面多刚体静力平衡独立装配，并对铰点反力做秩与唯一性分析；非唯一分量保持 `null`。
- 不包含轴向预紧、三维支承分配、惯性和摩擦。
- 基准姿态的自由度、虚功和平衡残差通过后，才扩展至 J2/J3/J4 单关节 1 Hz、±10° 全时序。

## 阶段门

1. 三维诊断必须明确三个模态的输出对应关系和主导残差约束。
2. 平面模型必须有且仅有三个机构自由度，三根推杆长度雅可比满秩。
3. 推杆虚功与势能微分必须在明确阈值内一致。
4. 平面静力反力不唯一时不得填入伪确定值。
5. 当前不开发摩擦圆。
