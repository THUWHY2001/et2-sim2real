# 头颈 J0/J1 灵敏度页面设计

## 目标

将头颈并联双推杆机构拆分为 J0 Roll 与 J1 Pitch 两个页面，展示机构运动、双向静/动摩擦折算、重力矩和 1 Hz、±10°周期结果。

## 已确认模型

- 推杆1：下端 `(-62,27,371.06)`，上端 `(-37.4,32,486.6)` mm。
- 推杆2：下端 `(-62,-27,371.06)`，上端 `(-37.4,-32,486.6)` mm。
- J0轴：R1 `(52,0,479.66)` 至 R2 `(40,0,479.66)`，Roll；J1保持0°，双推杆反向变化。
- J1轴：P1 `(-16,20,479.66)` 至 P2 `(-16,-20,479.66)`，Pitch；J0保持0°，双推杆同步变化。
- 头部与动平台合计质量 `2.447 kg`，质心 `(-9.851,0.204,408.752)` mm，重力沿全局 `-Z`。
- 正方向按轴线起点至终点的右手定则。

## 摩擦与预紧

- 鱼眼、P1/P2、R1/R2输入正反向静摩擦力矩与动摩擦力矩，单位 N·m。
- 推杆输入正反向静摩擦力与动摩擦力，单位 N。
- 每个连接副保留预紧力输入，作为对应实测摩擦的工况记录；不使用未知摩擦系数或预紧传递系数进行换算。
- 解算重力导致的推杆轴向力与活动轴支承反力；可选载荷修正采用 `T_f(q)=T_f,ref+k_N[N(q)-N_ref]`，`k_N` 默认0。
- J0中P1/P2无相对转动，J1中R1/R2无相对转动，不计入相应关节贡献。

## 输出

- 机构投影图与1 Hz动画；J0使用Y–Z正视，J1使用X–Z侧视。
- 各连接副瞬时传动系数、静摩擦启动力矩和动摩擦运行阻力。
- 重力矩、摩擦力矩、总需求力矩分别显示。
- 各鱼眼和活动轴两侧显示计算承载力，便于后续标定 `k_N`。
- 摩擦贡献度只在耗散项内部归一化，不把重力混入摩擦贡献。
