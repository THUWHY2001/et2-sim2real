# 腿足连接副统一编号设计

## 目的

让机构图、阻力输入和贡献度结果使用同一套编号，使读者能从排名直接定位到机构中的真实连接副。

## 方案

- 按完整左腿模型中25个运动副的稳定顺序编号为 `L01`～`L25`。
- J2、J3、J4 三个页面共用同一编号，不因当前分析关节不同而重新编号。
- 机构图在运动副中心标出 `Lxx`；图下增加“编号、连接副名称、类型、连接零件、原始模型名”对照表。
- 阻力输入、实时贡献度、周期贡献度、加载后贡献度统一显示“`Lxx 中文名称`”。
- J2/J3/J4 和三根推杆保留现有直观名称；原始 ADAMS 名称保留在对照表中用于追溯。

## 约束

- 不修改闭链运动学、阻力折算、质量属性和负载计算。
- 编号必须由模型数据确定，不能随贡献度排序或页面筛选变化。
- 图中只标运动副编号，硬点和质心维持当前显示逻辑，避免标签过密。

## 验收

- 任一贡献度条目的编号可在机构图和对照表中找到。
- 同一运动副在 J2/J3/J4 页面编号一致。
- 25个运动副无重复、无遗漏。
